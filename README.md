# پنل محلی خزش دیوار

پنل وب برای جستجوی آگهی‌های [دیوار](https://divar.ir) روی رایانه خودتان. رابط فارسی و راست‌به‌چپ است. داده‌ها و توکن ورود در پوشه `data/` روی همین دستگاه می‌مانند و به اینترنت دیگری فرستاده نمی‌شوند.

منطق جستجو، صفحه‌بندی، جزئیات و خواندن شماره از اسکریپت تأییدشده دسته زیبایی تهران گرفته شده است. API دیوار غیررسمی است و ممکن است عوض شود.

## نصب

پایتون ۳.۱۱ یا جدیدتر لازم است. در ویندوز هنگام نصب، گزینه **Add Python to PATH** را بزنید.

```bash
pip install -r requirements.txt
python run.py
```

مرورگر روی `http://127.0.0.1:8000` باز می‌شود. سرور فقط به `127.0.0.1` گوش می‌دهد. برای میزبان یا پورت دیگر:

```bash
python run.py --host 127.0.0.1 --port 8000 --no-browser
```

داکر (داخل کانتینر روی همه رابط‌ها گوش می‌دهد؛ آن را روی شبکه عمومی منتشر نکنید):

```bash
docker build -t divar-panel .
docker run --rm -p 127.0.0.1:8000:8000 -v divar-data:/app/data divar-panel
```

## استفاده

1. **کار تازه:** دسته را از فهرست انتخاب کنید یا اسلاگ آزاد بنویسید (مثلاً `beauty-and-haircare`). شهر پیش‌فرض تهران است (`1`). کلمه جستجو، فیلتر عنوان/توضیحات و حداکثر صفحه اختیاری‌اند.
2. **جزئیات** را اگر می‌خواهید توضیح آگهی پر شود روشن بگذارید. **شماره** فقط با حساب واردشده کار می‌کند؛ در این حالت خزش **انسانی** است (رویدادهای شماره/کپچا فیلد `egress_group` در `reveal_events` دارند): لیست در Chromium باز می‌شود، کارت‌های دیده‌شده جمع‌آوری می‌شوند، هر آگهی باز می‌شود و بعد از تأخیر تنظیم‌شده (پیش‌فرض **۲۵–۴۵ ثانیه** با پراکندگی تصادفی؛ **حداقل ۲۰ ثانیه** در کد و پنل اجبار می‌شود حتی اگر برای اکانت مقدار کمتر بگذارید) شماره خوانده می‌شود. هر **۴ شماره** پیش‌فرضاً **۱۰ دقیقه** مکث (با کمی پراکندگی) دارد. سقف غلتان **۵ شماره در ۱۰ دقیقه** و **۲۰ شماره در ساعت** برای هر اکانت است (در تنظیمات قابل تغییر با سقف منطقی). بعد از کپچا، اکانت حداقل **۴۵ دقیقه** کنار گذاشته می‌شود حتی اگر کپچا را دستی حل کنید؛ کپچای دوم در همان روز تهران تا نیمه‌شب بلوکه می‌ماند. سقف روزانه پیش‌فرض **۸۰** و حداکثر **۱۵۰** شماره است. اگر بعد از رفرش آگهی تازه نیاید، قبل از رفرش بعدی **عقب‌نشینی نمایی** (از ۵ دقیقه تا ۳۰ دقیقه) اعمال می‌شود. **فقط یک کار خزش انسانی** روی همین سرور/IP همزمان اجرا می‌شود. رویدادهای شماره/کپچا در SQLite (`reveal_events`) و از API `GET /api/reveal-events` قابل بررسی‌اند. پایان لیست با چند اسکرول پشت‌سرهم بدون آگهی تازه تشخیص داده می‌شود. **حداکثر اسکرول** برای حالت شماره می‌تواند صفر باشد (نامحدود).
3. شروع، مکث، ادامه و توقف از همان صفحه است. اگر برنامه را ببندید، کارِ در حال اجرا بعد از اجرای دوباره از آخرین صفحه ادامه پیدا می‌کند (SQLite).
4. برگه **نتایج** ردیف‌ها را زنده نشان می‌دهد: عنوان، لینک، محله، قیمت، خلاصه، شماره، نام کار، زمان. جستجو، مرتب‌سازی و خروجی CSV (با BOM) و Excel راست‌به‌چپ با سرستون فارسی برای یک کار یا نتیجه فیلترشده هست.
5. برگه **حساب‌ها (Chromium):** هر اکانت پروفایل جدا، **پروکسی اختیاری** (http/https/socks5) و **اثرانگشت مرورگر پایدار** دارد. چند اکانت **بدون پروکسی جدا** روی یک سرور عملاً یک **گروه خروجی (IP مشترک)** هستند؛ دیوار کپچا را به IP/اثرانگشت می‌زند نه فقط به شماره حساب. برای استفاده واقعی از چند اکانت، برای هر کدام **پروکسی/IP متفاوت** بگذارید (دکمه **تست پروکسی** IP خروجی را نشان می‌دهد). بعد از کپچا، کل گروه خروجی (نه فقط همان اکانت) موقتاً کنار گذاشته می‌شود.
6. برگه **تنظیمات:** نرخ درخواست ناشناس، تأخیر پیش‌فرض، مکث دسته‌ای، سقف‌های ۱۰ دقیقه/ساعتی، کول‌داون بعد کپچا، سقف روزانه هر **گروه خروجی** (پیش‌فرض ۵۰)، و مکث گروه بعد کپچا (پیش‌فرض ۹۰ دقیقه). هنگام ارتقا، تأخیرهای قدیمی (مثلاً ۱–۵ ثانیه) و سقف‌های خیلی بالا خودکار به مقادیر امن‌تر مهاجرت می‌شوند.

## آزمون

```bash
python -m pytest -q
```

آزمون زنده یک جستجو و یک جزئیات واقعی (بدون ورود و بدون پیامک) می‌زند. اگر شبکه نباشد همان آزمون خطا می‌دهد.

## هشدارها

- دیوار برای دیدن شماره **سقف روزانه** دارد. با محدودیت، آن حساب تا روز بعد کنار گذاشته می‌شود. سقف و سرعت را بالا نبرید.
- از **حساب ثانویه** استفاده کنید. استفاده زیاد ممکن است حساب را محدود کند.
- جمع‌آوری خودکار خلاف **شرایط استفاده دیوار** است. مسئولیت استفاده، رعایت حریم خصوصی و نفرستادن پیام انبوه با شماست.
- دیوار بی‌سروصدا نرخ را کم می‌کند (در عمل فاصله جزئیات بعد از چندصد درخواست از حدود ۱٫۵ ثانیه به حدود ۸ ثانیه رسیده است).
- توکن مثل رمز است. پوشه `data/` را به گیت یا کسی ندهید.
