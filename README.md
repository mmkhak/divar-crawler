# پنل محلی خزش دیوار

پنل وب برای جستجوی آگهی‌های [دیوار](https://divar.ir) روی رایانه خودتان. رابط فارسی و راست‌به‌چپ است. داده‌ها و توکن ورود در پوشه `data/` روی همین دستگاه می‌مانند و به اینترنت دیگری فرستاده نمی‌شوند.

منطق جستجو، صفحه‌بندی، جزئیات و خواندن شماره از اسکریپت تأییدشده دسته زیبایی تهران گرفته شده است. API دیوار غیررسمی است و ممکن است عوض شود.

## نصب

پایتون ۳.۱۱ یا جدیدتر لازم است. در ویندوز هنگام نصب، گزینه **Add Python to PATH** را بزنید.

```bash
pip install -r requirements.txt
python run.py
```

مرورگر روی `http://127.0.0.1:8000` باز می‌شود. سرور فقط به `127.0.0.1` گوش می‌دهد. برای میزبان یا پورت دیگر:

```bash
python run.py --host 127.0.0.1 --port 8000 --no-browser
```

داکر (داخل کانتینر روی همه رابط‌ها گوش می‌دهد؛ آن را روی شبکه عمومی منتشر نکنید):

```bash
docker build -t divar-panel .
docker run --rm -p 127.0.0.1:8000:8000 -v divar-data:/app/data divar-panel
```

## استفاده

1. **کار تازه:** دسته را از فهرست انتخاب کنید یا اسلاگ آزاد بنویسید (مثلاً `beauty-and-haircare`). شهر پیش‌فرض تهران است (`1`). کلمه جستجو، فیلتر عنوان/توضیحات و حداکثر صفحه اختیاری‌اند.
2. **جزئیات** را اگر می‌خواهید توضیح آگهی پر شود روشن بگذارید. **شماره** فقط با حساب واردشده کار می‌کند.
3. شروع، مکث، ادامه و توقف از همان صفحه است. اگر برنامه را ببندید، کارِ در حال اجرا بعد از اجرای دوباره از آخرین صفحه ادامه پیدا می‌کند (SQLite).
4. برگه **نتایج** ردیف‌ها را زنده نشان می‌دهد: عنوان، لینک، محله، قیمت، خلاصه، شماره، نام کار، زمان. جستجو، مرتب‌سازی و خروجی CSV (با BOM) و Excel راست‌به‌چپ با سرستون فارسی برای یک کار یا نتیجه فیلترشده هست.
5. برگه **حساب‌ها:** شماره را وارد کنید، «دریافت کد» را بزنید، کدی که دیوار پیامک کرده را خودتان بنویسید. توکن محلی ذخیره می‌شود. وضعیت: فعال، منقضی (۴۰۱؛ دوباره وارد شوید)، محدود برای همان روز (۴۰۳/۴۲۹ یا پیام سقف). سقف پیش‌فرض هر حساب حدود ۵۰ شماره در روز است و نیمه‌شب به وقت تهران صفر می‌شود. شماره‌ها نوبتی بین حساب‌های آماده پخش می‌شوند. هر حساب تأخیر تصادفی خودش را دارد (پیش‌فرض ۲۰ تا ۴۰ ثانیه) و می‌تواند پروکسی HTTP جدا داشته باشد.
6. برگه **تنظیمات:** نرخ درخواست ناشناس (پیش‌فرض حدود ۱ در ثانیه). اگر دیوار کند یا ۴۲۹ جواب بدهد، فاصله موقتاً بیشتر می‌شود. دکمه به‌روزرسانی شهرها اگر API شهر پاسخ بدهد فهرست را عوض می‌کند؛ وگرنه همان فهرست همراه برنامه می‌ماند. دسته‌ها از فایل همراه برنامه بارگذاری می‌شوند.

## آزمون

```bash
python -m pytest -q
```

آزمون زنده یک جستجو و یک جزئیات واقعی (بدون ورود و بدون پیامک) می‌زند. اگر شبکه نباشد همان آزمون خطا می‌دهد.

## هشدارها

- دیوار برای دیدن شماره **سقف روزانه** دارد. با محدودیت، آن حساب تا روز بعد کنار گذاشته می‌شود. سقف و سرعت را بالا نبرید.
- از **حساب ثانویه** استفاده کنید. استفاده زیاد ممکن است حساب را محدود کند.
- جمع‌آوری خودکار خلاف **شرایط استفاده دیوار** است. مسئولیت استفاده، رعایت حریم خصوصی و نفرستادن پیام انبوه با شماست.
- دیوار بی‌سروصدا نرخ را کم می‌کند (در عمل فاصله جزئیات بعد از چندصد درخواست از حدود ۱٫۵ ثانیه به حدود ۸ ثانیه رسیده است).
- توکن مثل رمز است. پوشه `data/` را به گیت یا کسی ندهید.
