اکانت‌های Chromium

      
هر اکانت یک پروفایل جدا دارد. اکانت‌های وصل‌شده همزمان شماره می‌گیرند. برای لاگین: «لاگین این اکانت» را بزن و در پنجره Chromium وارد شو.

      

        
        
        
        
      

      
      
هر اکانت می‌تواند پروکسی جدا داشته باشد (http/https/socks5). رمز پروکسی در API و لاگ‌ها نمایش داده نمی‌شود. چند اکانت بدون پروکسی جدا، روی یک IP سرور همان گروه خروجی را دارند.

      
حداقل تأخیر بین هر شماره در برنامه ۲۰ ثانیه است؛ مقادیر کمتر خودکار بالا برده می‌شوند.
